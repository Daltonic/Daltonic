### Who I am

Port Harcourt based. Remote by default. I run **Dapp Mentors** — a school and a product studio in the same house. Ten years in production software. Since 2020 the work has been AI, blockchain, and the interfaces that make both usable.

I write the code, put it on a public network or a real server, then turn that path into courses and YouTube videos so other builders are not stuck on half-finished tutorials.

| Focus | What that means in practice |
| --- | --- |
| **Applied AI** | RAG, agents, LLM judges, Whisper/Ollama pipelines, bots on Discord and Telegram |
| **Blockchain** | Solidity, Anchor/Rust, ERC + SPL tokens, wallets, gas, tests, mainnet deploys |
| **Frontend** | React, Next.js, TypeScript, streaming UIs, data-heavy dashboards |
| **Teaching / DevRel** | 5,800+ subscribers, 140+ tutorials, 10 paid courses, grants from DFINITY and Sia |

**Open for** full-time, contract, or consult work in those four seats. Prefer teams that care about shipping over slide decks.
